# Clean Code Design Pattern - Product Management System
A school assignment to showcase use of Design Patterns and using the rules of Clean Coding. 

## Features

- Fully runs in the terminal/command-line interface (CLI)   
- Simple, beginner-friendly Java code  
- Add, View, Update, Delete Products
- Sort your products using different sorting methods and algorithms.

## Requirements

- Java 8 or higher installed  
- Terminal or command prompt to run the game  

## Installation

1. Clone the repository or download the source code.  
2. Open a terminal in the project directory.  
3. Compile the Java files:

```bash
javac *.java
```
